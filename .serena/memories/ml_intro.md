# ML Intro Lab (`ml-intro`)

- **6 linear stages** (`src/features/ml-intro/domain/stages.ts`): `1. strategy` -> `2. tokenize` -> `3. score` -> `4. train` -> `5. evaluate` -> `6. generalize`.
  - Stage 1 (`strategy.ts`): 10-word intuition strategy with 5 discrete polarity tiers (`[-2, 2]` integer weights: `−2 强正常`..`+2 强垃圾`), 6 10-word SMS examples, and signed risk score cutoff `w·x >= +1` (deliberately no synthetic probabilities; requires both positive and negative polarity choices without polluting neutral words).
  - Stage 3 (`ScorePanel.tsx`, `state.ts`): Starts from a prefilled spam blacklist (`b = +0.4`, spam weights pre-set, normal words `0`) with a live Sigmoid S-curve SVG visualizer (`z = w·x + b -> σ(z)`), focusing students on why `b < 0` and negative counter-weights are needed for probabilistic calibration.
- **SQLite migration (`SCHEMA_VERSION = 17` in `server/db/client.ts`)**: Legacy 5-stage `ml-intro` progress (`passed_stages`, `draft_graph`, `draft_revisions`, `submissions.stage_index` `1..5`) shifts forward `+1` to `2..6` on upgrade; `mlStageUnlocked` allows `passedStages.includes(index)` so migrated rows keep linear continuity.
- **Corpus split & classroom scrubbing**: 2,000 classroom-curated, PII-redacted (`TEL`/`URL`/`ID`/`NUM`) SMS rows (~14.1% spam) stored as `<label>\t<text>`:
  - Browser & judge (`src/features/ml-intro/domain/corpusData.ts`): `TRAIN_ROWS` (1,400) + `VAL_ROWS` (300). Train vocabulary is built strictly from `TRAIN_ROWS` to prevent OOV leakage.
  - Server-only held-out test (`server/judge/ml-intro/hiddenCorpus.ts`): `HIDDEN_TEST_ROWS` (300). Never import into `src/` or return raw hidden texts or detailed hidden-test metrics in judge responses.
- **Unified engine**:
  - `tokenizeWords` (`src/features/ml-intro/domain/tokenizer.ts`) performs forward-maximum-matching solely against the fixed static `CN_LEXICON` (`cnLexicon.ts`, MIT general lexicon, independent of `trainVocab`). Both corpus ingestion (`corpus.ts`, `hiddenSet.ts`) and UI inspection (`inspectCorpusMessageWithModel` / `inspectMessageWithModel`) share this single boundary so model predictions and explanations match bit-for-bit (`0/300` drift).
  - `trainLogisticRegression` (`logreg.ts`) uses seeded per-epoch Fisher-Yates SGD shuffling (`DEFAULT_TRAIN_SEED = 2026`, `shuffleEpochs: true` default) alongside invariant optional `bgdHistory`.
- **Prompt & stage gating**: Client panels and `server/judge/ml-intro/judge.ts` share `ML_STAGES[i].prompts` and semantic threshold constants in `stages.ts`. Stage 6 evaluates public validation loss (`<= 0.14`) + held-out accuracy/precision/recall gates server-side, returning only public validation metrics plus a single sealed `hidden-blind-exam` pass/fail part to prevent test-set hill-climbing.
- **Experiment comparison**: Stage 4/6 `ui/ExperimentComparison.tsx` keeps one component-local observation of public results, independent of draft/autosave/judge payloads; leaving the stage clears it. Parameter-change hints exclude replay epoch and BGD visibility. Intra-epoch plots show validation-loss checkpoints (10 per epoch for the full training set), not every SGD update.
- **Classroom mode & pinned URL stage** (`lesson/state.ts`, `ui/MlIntroLabPage.tsx`): `?classroom=1&stage=N` or the rail toggle sets `classroomMode` to allow free tab preview across all 6 stages while keeping server `passedStages` (`mlStageUnlocked`) judge gating strict. `pinnedStage` (`number | null`) distinguishes explicit `stage=1` from omitted `stage` across `load-project`.
- **Corpus split cache & deferred training consistency** (`logreg.ts`, `TrainPanel`, `EvaluatePanel`, `GeneralizePanel`): `getPreparedPublicSplit(trainCount)` caches vocab and vectorized public splits; panels using `useDeferredValue` guard submission during `isStale` and bind metrics/comparison records to settled `run.*` parameters.
- **Stage 4 order & optional 1D slice** (`TrainPanel`, `LossDerivationCard`, `lossSlice.ts`, `WeightLossSliceExplorer`): Auto-training + 3-baseline validation comparison (all-zero, `run.baselineAcc` majority class with train-split `run.trainSpamRate` constant-prior BCE, and trained model comparing accuracy and BCE independently) precedes single-step explanation, collapsed derivation appendix (single-sample `ℓᵢ` for SGD vs batch mean `L` for BGD), and collapsed 1D slice explorer (`ContextScopedState` resets trail when `(word, contextMode, trainedModel)` changes).
